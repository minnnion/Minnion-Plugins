# Soundboard

Play sound files from your keys.

Each key plays an MP3, WAV, WMA or M4A file at its own volume. Press again to stop it or start it over, and one key stops everything. Uses Windows' own player, so nothing else is needed.

## Install

Open **Marketplace** in MinnionDeck and press **Install**, or tick it in the MinnionDeck setup. Its profile is added with it.

## Actions

- Play a sound
- Stop all sounds

## You need

- Your own sound files
