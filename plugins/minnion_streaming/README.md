# Streaming

OBS Studio, Twitch and YouTube chat on your keys, live.

Go live, record, switch scenes, mute sources and save replays in OBS, with each key showing OBS's live state. With OBS on this PC there's nothing to type: tick Enable WebSocket server in OBS and it connects by itself. Sign in to Twitch once for viewers, followers, chat, clips, markers, ads and chat modes. Type your YouTube @handle to read your live chat, with no sign-in. Set up only the ones you use.

## Install

Open **Marketplace** in MinnionDeck and press **Install**, or tick it in the MinnionDeck setup. Its profile is added with it.

## Actions

- Go live
- Record
- Pause recording
- Switch scene
- Mute a source
- Show or hide a source
- Replay buffer
- Save replay
- Viewers
- Followers
- Live chat
- Make a clip
- Stream marker
- Run an ad
- Slow mode
- Emote-only chat
- Send a chat message
- Set stream title
- Live chat

## Settings

- Check OBS
- Sign in to Twitch
- Check YouTube chat
- Sign out of Twitch
- YouTube channel
- Twitch chat to show
- OBS computer (only if OBS is on another PC)
- OBS password (only if OBS is on another PC)
- OBS port (only if OBS is on another PC)

## You need

- OBS Studio 28 or newer, for the OBS keys
- A Twitch account, for the Twitch keys
