# Speech

Reads text aloud with 37 natural US and UK voices, on this PC.

A key that speaks: type what it should say, pick a voice, press. The voices run on this PC, so nothing is sent anywhere and it works offline.

Open **Marketplace** in MinnionDeck and press **Install**, or tick it in the MinnionDeck setup. Its profile is added with it.
